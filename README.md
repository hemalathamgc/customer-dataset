# Customer Behavior Analytics Dashboard

## Project Description

Customer Behavior Analytics Dashboard is a Streamlit application that helps analyze customer purchasing behavior.

## Features

- Upload CSV Dataset
- Data Cleaning
- Dashboard KPIs
- Sales Analysis
- Customer Analysis
- Category Analysis
- Payment Method Analysis
- Interactive Charts
- Download Processed Dataset

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- SQLite

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
